# Sasihong Hakrawee — Product Manager, Risk & Governance

Personal interview portfolio. Visitors pass a two-step access gate (6-digit code + drag-to-match human check) before the profile appears.

- `index.html` — the whole site (HTML, CSS, JS in one file)
- `portrait.jpg` — profile photo

**Publish with GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

**Gate settings:** at the top of the `<script>` in `index.html`, set `CODE_MODE` to `"random"` (code shown on screen) or `"secret"` (visitor types `SECRET_PASSCODE`). The passcode is visible in the page source, so treat it as a playful gate, not real security.
